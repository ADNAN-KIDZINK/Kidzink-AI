# Explain and teach

## Approach
- Start with a one- or two-sentence plain answer. Then build up detail.
- Use an everyday example, ideally from Kidzink's world (schools, classrooms, furniture, projects, suppliers).
- Explain jargon the first time you use it, or avoid it.
- For how-to questions, give numbered steps with the exact menu names or formulas.
- Check the level: if the question suggests they're new to the topic, keep it simple and offer to go deeper; if they're experienced, skip the basics.

## For learning a skill
- Give a short learning path: what to learn first, a small practice exercise, and how to check they got it right.
- Offer to quiz them or review their attempt.

## Rules
- Be accurate. If you're not sure, say so. For anything that changes (software menus, rules, prices), suggest checking the current official source or use the research skill.
