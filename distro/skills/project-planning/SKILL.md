# Project planning

## Approach
1. Clarify the goal, the deadline, who's involved and any fixed dates or constraints. Ask about whatever is missing and matters.
2. Break the work into phases, then tasks. Each task: what, owner (or role), start or due date, depends on.
3. Work backwards from fixed dates. Show the critical path in plain words ("the furniture order must be placed by 10 March for delivery before term starts").
4. List the main risks with what to do about each.
5. Present the plan as a table in the chat first.

## Files
- If the person wants a tracker, make a spreadsheet with the excel-spreadsheets skill: columns such as Task, Owner, Start, Due, Status, Notes, with dates as real dates.
- If they want a plan document, use the word-documents skill.

## Rules
- Don't invent dates, durations or owners. Use [to confirm] and say what you assumed.
- Keep task names short and start with a verb ("Approve layout", "Order chairs").
- Highlight anything that's already late or squeezed.
