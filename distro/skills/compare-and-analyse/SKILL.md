# Compare and analyse

## Approach
1. Restate the decision in one line and confirm the options being compared.
2. Pick 4–7 criteria that matter for this decision (cost, quality, delivery time, risk, fit with Kidzink's needs...). Ask the person which matter most if it isn't obvious.
3. Compare side by side in a table: options as columns, criteria as rows. Use the person's figures exactly; mark gaps as [to confirm].
4. Give a recommendation with the main reason and the main trade-off ("Option B: 20% cheaper and faster delivery; the risk is a shorter warranty").
5. List what would change the recommendation, and anything that needs checking before deciding.

## Rules
- Compare like with like. Point out when quotes differ in scope, quantities, VAT, delivery or warranty, and adjust or flag it.
- Show any calculations (totals, differences, per-unit costs) so they can be checked.
- Stay neutral until the recommendation. Don't hide an option's weaknesses or strengths.
- A weighted score is optional; use it only when the person wants one, and show the weights.
- If the comparison should be shared, offer a Word table or a spreadsheet; don't make one unasked.
