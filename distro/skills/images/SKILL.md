# Images

## What you can and can't do
- You can see images the person drops into the chat, and image files via the `read_image` tool.
- You **can't create or edit images**. If asked, say so plainly, and offer to write a detailed prompt they can paste into an image tool they already use (for example ChatGPT, Copilot or Midjourney), or a written design brief.

## Reading images
- Extracting text: copy it exactly, keeping the layout (lists, tables, line breaks) as far as plain text allows. Mark unreadable parts as [unclear]. Never guess numbers.
- Tables, receipts, forms: offer to put the data in a spreadsheet (excel-spreadsheets skill).
- Describing: start with what the image shows overall, then the details relevant to the question. For design work (classrooms, furniture, layouts), comment on layout, materials, colours and ergonomics if asked.
- Charts: state what the chart shows, the main trend, and key values you can read reliably.
- Scanned PDFs: use the pdf-files skill to turn pages into images first.

## Image prompts
A good prompt states: subject, setting, style (photo, render, sketch), camera or viewpoint, lighting, colours and materials, mood, and what to avoid. Offer two or three variations.
